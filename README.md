# Genera

A desktop workspace for Claude Code, Codex and Cursor.

[Download the latest macOS release](https://github.com/vasdanon/genera-releases/releases/latest)

## Install

1. Use a Mac with Apple Silicon (M1 or newer).
2. Download and open the DMG, then drag Genera to Applications.
3. Open Genera and connect your own agent accounts.

Releases are signed with Developer ID and notarized by Apple.

## Updates

Starting with Genera 0.13.1, the app checks this repository for new versions. Open Settings → General → Genera updates to check manually. When the download is ready, choose Update and restart.
